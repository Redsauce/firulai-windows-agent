# Windows agent 0.20.7

Adds compatibility with Firulai's Agent Status list: `Agente instalado` is equivalent to `Activo`. A covered `Agente Desconectado` can report again; pending installations, uninstalled agents and systems without coverage remain blocked. Older status names remain readable during the transition.

Includes the previous releases' immediate agent-version reporting, signed automatic upgrades, recovery protections and five-minute retries after update network failures. Configuration, UUID and daily inventory scheduling are preserved.

Includes an isolated retry-preview script for repeatable diagnostics without installing anything or restarting the real service.

Validation: 25 eligibility checks; signed manifests, tampered packages, version ordering, downgrade rejection, network failures/recovery, concurrent checks, retry scheduling and resume behavior; 28 large-inventory checks; HTTP redirect handling; multilingual installer compiled. The actual agent validator verified the release manifest, signature and installer package.

RSM's activation and inventory receivers must recognize the new names to process inventories. The API compatibility adapter for Linux 0.4.1–0.4.5 is a separate RSM change; this Windows version recognizes both names directly.

For the next-day automatic-update test, keep the current 0.20.6 installation and let the service check the published update on the next startup. This release preparation does not install or restart the local agent. A full end-to-end automatic upgrade on the user's PC remains to be observed.
