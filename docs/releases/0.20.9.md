# Windows 0.20.9

Fixes the installer startup failure after uninstalling the agent or on a clean
machine: `An attempt was made to expand the app constant before it was initialized`.

Early detection now reads the registered installation directory, falling back to
Program Files/RSAgent, without expanding `{app}` before the wizard initializes it.
The same helper checks for the executable and uninstaller and prepares the path
shown in reinstall instructions.

The agent retains the hourly update checks, signed package verification,
independent inventory retries and confirmed uninstallation behavior from 0.20.8.

Validation includes a native Inno Setup startup probe that runs before directory
initialization and cancels without installing or modifying services, the existing
upgrade and inventory checks, multilingual compilation and verification of the
signed release package by the actual agent.

After publishing, select Windows 0.20.9 in RSM to enable its download through
Firulai and automatic updates from agents using the RSM catalog. Publishing a
GitHub release alone does not change that selection. Reinstallation with the
same UUID and token still requires a real end-to-end validation; compilation and
startup checks do not mark that workflow as complete.
