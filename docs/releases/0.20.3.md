# Windows 0.20.3

Actualizacion sobre una instalacion existente sin desinstalar, conservando
UUID, token, idioma y configuracion. Actualizacion automatica mediante
manifiesto RSA/SHA-256 firmado y comprobacion del paquete descargado.

El servicio comprueba versiones estables superiores; los fallos de descarga
no impiden el inventario. Un helper independiente gestiona la instalacion
silenciosa, conserva el ejecutable anterior y prepara recuperacion al arrancar.

Los agentes anteriores a 0.20 requieren una primera actualizacion manual.
La release incluye FirulaiAgent.exe, agent-update.json, agent-update.json.sig
y RELEASE_CHECKSUMS.txt. La clave privada nunca forma parte de la release.

Validacion: pruebas de version y firma, compilacion del instalador multidioma,
actualizaciones locales reales, inventario enviado y recuperacion forzada
correcta. El interruptor de Firulai se implementara al final, por decision
del usuario. Las pruebas de corte de corriente quedan pendientes.
