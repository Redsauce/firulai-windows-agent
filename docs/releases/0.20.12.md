# Windows 0.20.12: aviso de recopilación

El flujo común manual (`--run-once`) y del servicio comunica inicio, heartbeat
cada 45 segundos y fin al terminar el envío o fallar. Firulai muestra
«Recopilando datos» en listado y detalle. No se añade un estado «Completado».

El reporte utiliza HTTPS sin redirecciones y no bloquea el inventario si el
backend no está disponible. Los avisos caducan tras tres minutos sin heartbeat.
Las ejecuciones concurrentes utilizan identificadores distintos.

Paquete preparado con el instalador multidioma y manifiesto RSA firmado para
actualización automática. Conserva configuración, UUID y el servicio existentes.
Requiere el endpoint de recopilación del backend Firulai; no cambia objetos RSM.
