# Windows agent 0.20.18

File inventory now includes the file path, original filename, product name,
publisher, raw ProductVersion and FileVersion, and the selected version source.
Distinct physical file observations are preserved. When ProductVersion contains
only a description, a valid FileVersion is used instead. Numeric comma-separated
versions are normalized while meaningful version suffixes are preserved.

The receiver must store inventory evidence in the configured component property.
CVE decisions remain in the server matcher and require matching official evidence.
An agent update alone does not establish that a vulnerability is fixed.
