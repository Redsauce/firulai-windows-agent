# Windows agent 0.20.20

Inventories above 6 MiB are compressed once and sent through the existing
newServerData event as numbered gzip/base64 fragments. Each binary fragment
is at most 3 MiB; the complete multipart request remains bounded to 7 MiB.
Inventories up to 6 MiB keep the compatible 0.20.19 transport.

A durable pending snapshot survives connection failures and restarts. Retries
reuse the same upload identifier and bytes, including parts whose delivery was
uncertain. A previous pending snapshot is queued before a newly collected one.
HTTP success confirms event queueing, not completed inventory processing.

The compatible receiver authenticates the System before staging parts in a
private disk directory. It validates per-part and whole compressed/raw hashes,
declared sizes and complete gzip before running inventory reconciliation. Missing
parts never reach reconciliation. Duplicates and out-of-order parts are supported.
Completed uploads are remembered for 24 hours; failed processing can be retried.
A crashed processing execution can resume under the existing System lock. This
does not provide a distributed transaction with RSM writes; reconciliation after
an interrupted process must remain idempotent.

Bounds: 64 MiB uncompressed inventory, 65 MiB compressed, at most 22 fragments,
two incomplete uploads per authenticated System, 1 GiB staging and 1024 sessions
per executor, and cleanup of sessions idle over 24 hours. Current execution uses
one receiver node; independently executing nodes require shared staging and
compatible filesystem locks before enabling this protocol across them.

Deploy and verify the compatible Upload JSON Server data receiver before
publishing/activating this agent. The receiver retains support for older agents.

Validation includes high-entropy multi-part inventories, lost HTTP responses,
durable replay, duplicates, missing/reordered parts, processing failures, quota
and expiry checks, corrupted data, authenticated client isolation, concurrent
duplicates and C# to Python interoperability, plus updater and signed bundle tests.
