# Windows agent 0.20.5

- Retry failed automatic update checks every five minutes instead of blocking checks for 24 hours.
- Use a separate update retry timer, so a successful inventory does not stop update retries and a pending inventory retry is preserved.
- Serialize checks to prevent concurrent downloads and duplicate installer launches.
- Resume outstanding update checks after sleep and cancel retry timers when the service stops.
- Log the next retry time, network error classification, disabled updates and suppressed repeat installation attempts.
- Keep signed manifest/package verification, opt-out, anti-downgrade and installer recovery protections.

Migration: agents 0.20.3/0.20.4 retain their old retry behavior until they install this release. If their initial check failed, restart the service once the network is available, or install this release over the existing agent. Do not uninstall or downgrade.
