# Firulai Windows Agent 0.19.3

Corrige la recogida de versiones de archivos que contienen caracteres de control no validos en XML, como el caso de git2.dll encontrado durante la investigacion de componentes duplicados.

- Sanea los metadatos ProductVersion antes de incorporarlos al inventario.
- Usa FileVersion como alternativa cuando ProductVersion queda vacio tras sanearlo.
- Mantiene el instalador multidioma y la configuracion de identidad/cobertura existente.

El receptor de inventario tambien debe estar actualizado. El agente no elimina duplicados historicos por si solo.

Validacion: 28 comprobaciones de inventarios grandes y metadatos; prueba del endpoint del instalador sin instalar ni cambiar el servicio.

Para actualizar una instalacion existente, el instalador requiere desinstalar primero la version anterior. La desinstalacion desconecta el sistema en Firulai y conserva sus datos; reinstalar con el mismo UUID y token.
