1. 目的

代理是技术资产清单和漏洞管理支持工具。它作为 Windows 服务安装，定期收集
计算机的技术信息，并通过 HTTPS 发送到 Firulai，以维护资产清单并与已知漏洞
进行关联。

代理不能替代安全审计、专业分析、预防、更新、备份或事件响应措施。

4. 收集的信息

代理可能收集并发送到 Firulai 的信息包括：主机名、FQDN、分配的 UUID、Windows
版本、版本类型、构建号、架构、时区、收集日期、代理版本、硬件信息、检测到的
磁盘、已安装软件和软件包的名称及版本、包管理器、关键系统组件版本、运行元数据、
错误信息和技术日志。

代理使用 UUID 识别系统，并使用 Agent token 授权与 Firulai 的通信。该 token
本地存储在仅限 SYSTEM 和 Administrators 访问的配置文件中。

代理并非设计用于故意收集密码、私钥或用户文档内容。但是，技术元数据在某些环境
下可能构成个人数据或机密信息。您必须评估该情况，并采取必要的保护措施和法律
依据。

5. 后台运行

安装后，代理作为自动 Windows 服务运行，执行首次资产清单，尝试每日更新，可能
重试失败的提交，并在本地保存配置、状态、资产清单和技术日志。它需要与 Firulai
建立 HTTPS 连接。

卸载会删除本地服务和文件，但不会自动删除已存储在 Firulai 中的资产清单。系统
可能被标记为断开连接或非活动，远程数据必须在 Firulai 中管理。

6. 安全和授权使用

您不得使用代理在未经许可的情况下监控、盘点或访问计算机。请保持 Windows 和
保护机制为最新状态，控制管理员账户，并报告任何 Agent token 暴露或未经授权
使用的疑虑。

资产清单和漏洞结果可能包含错误、遗漏、误报、延迟或与计算机真实状态不一致的
情况。在作出影响可用性、完整性或安全性的决定之前，请核实结果。
