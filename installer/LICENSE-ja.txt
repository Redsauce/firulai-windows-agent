FIRULAI INVENTORY AGENT FOR WINDOWS

契約バージョン: 2026年7月20日

ソフトウェアをインストールまたは使用する前に、この文書をよくお読みください。

このライセンス契約および利用通知 (「本契約」) は、Redsauce が Firulai
プラットフォーム向けに提供する Firulai Inventory Agent for Windows
(「エージェント」) のインストールおよび使用を定めるものです。

本契約に同意してインストールを続行することにより、お客様は本条件を読み、
同意し、対象のコンピューターおよび組織においてエージェントをインストール
および実行する十分な権限を有することを確認します。すべての条件に同意しな
い場合は、エージェントをインストールまたは使用しないでください。

1. 目的

エージェントは、技術インベントリおよび脆弱性管理を支援するツールです。
Windows サービスとしてインストールされ、コンピューターの技術情報を定期的
に収集し、HTTPS により Firulai へ送信して、インベントリを維持し既知の脆弱
性と関連付けます。

エージェントは、セキュリティ監査、専門的分析、予防、更新、バックアップ、
またはインシデント対応の代替ではありません。

2. ライセンス

Redsauce は、お客様が所有、管理、または明示的に監視を許可されたシステムに
限り、かつ認可された Firulai アカウントまたはサービスでのみ、エージェントを
インストールおよび実行するための限定的、非独占的、譲渡不可、取消可能な

3. 権限と責任

インストールには管理者権限が必要です。お客様は、自動起動する Windows
サービスをインストールし、ここに記載された技術インベントリを収集および送信
し、対応する Firulai アカウントに関連付けられた UUID、エイリアス、および
Agent token を使用する権限を有することを確認します。

導入前に必要な社内、雇用上、契約上、その他の承認を取得する責任はお客様に
あります。インストーラー、UUID、および Agent token を保護し、アクセスを
認可された担当者に限定してください。

4. 収集される情報

エージェントは、ホスト名、FQDN、割り当てられた UUID、Windows のバージョン、
エディション、ビルド、アーキテクチャ、タイムゾーン、収集日時、エージェント
のバージョン、ハードウェア情報、検出されたディスク、インストール済み
ソフトウェアおよびパッケージの名称とバージョン、パッケージマネージャー、
主要システムコンポーネントのバージョン、運用メタデータ、エラー、技術ログを
Firulai に送信することがあります。

エージェントは UUID によりシステムを識別し、Agent token により Firulai との
通信を認可します。トークンは SYSTEM および Administrators のみに制限された
ローカル設定ファイルに保存されます。

エージェントは、パスワード、秘密鍵、ユーザー文書の内容を意図的に収集する
よう設計されていません。ただし、技術メタデータは環境によって個人情報または
機密情報となる場合があります。お客様はこれを評価し、必要な保護措置および
法的根拠を適用する必要があります。

5. バックグラウンド動作

インストール後、エージェントは自動 Windows サービスとして動作し、初回
インベントリを実行し、日次更新を試み、失敗した送信を再試行する場合があり、
設定、状態、インベントリ、技術ログをローカルに保存します。Firulai への HTTPS
接続が必要です。

アンインストールによりローカルのサービスおよびファイルは削除されますが、
Firulai に既に保存されたインベントリは自動的には削除されません。システムは
切断または非アクティブとして表示される場合があり、リモートデータは Firulai
から管理する必要があります。

6. セキュリティおよび認可された使用

許可のないコンピューターを監視、インベントリ化、またはアクセスするために
エージェントを使用してはなりません。Windows および保護機構を最新に保ち、
管理者アカウントを管理し、Agent token の漏えいまたは無許可使用の疑いを報告
してください。

インベントリおよび脆弱性の結果には、誤り、欠落、誤検出、遅延、または実際の
状態との差異が含まれることがあります。可用性、完全性、またはセキュリティに
影響する決定を行う前に結果を確認してください。
