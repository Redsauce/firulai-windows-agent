FIRULAI INVENTORY AGENT FUER WINDOWS

Version der Vereinbarung: 20. Juli 2026

Bitte lesen Sie dieses Dokument sorgfaeltig, bevor Sie die Software
installieren oder verwenden.

Diese Lizenzvereinbarung und Nutzungshinweise ("Vereinbarung") regeln die
Installation und Nutzung des Firulai Inventory Agent fuer Windows ("Agent"),
veroeffentlicht von Redsauce zur Verwendung mit der Firulai-Plattform.

Wenn Sie diese Vereinbarung akzeptieren und mit der Installation fortfahren,
bestaetigen Sie, dass Sie diese Bedingungen gelesen haben und akzeptieren und
dass Sie ausreichend berechtigt sind, den Agent auf dem betreffenden Computer
und in der betreffenden Organisation zu installieren und auszufuehren. Wenn Sie
nicht allen Bedingungen zustimmen, installieren oder verwenden Sie den Agent
nicht.

1. ZWECK

Der Agent ist ein Werkzeug fuer technisches Inventar und zur Unterstuetzung des
Schwachstellenmanagements. Er wird als Windows-Dienst installiert, sammelt
regelmaessig technische Informationen des Computers und sendet sie per HTTPS an
Firulai, damit das Inventar gepflegt und mit bekannten Schwachstellen korreliert
werden kann.

Der Agent ersetzt keine Sicherheitspruefung, professionelle Analyse,
Praevention, Aktualisierung, Sicherung oder Reaktion auf Sicherheitsvorfaelle.

Sie erwerben kein Eigentum am Agent oder an Firulai. Sie duerfen den Agent nicht

4. ERHOBENE INFORMATIONEN

Der Agent kann an Firulai senden: Hostname, FQDN, zugewiesene UUID, Windows-
Version, Edition, Build, Architektur, Zeitzone, Erhebungsdatum, Agent-Version,
Hardwareinformationen, erkannte Datentraeger, Namen und Versionen installierter
Software und Pakete, Paketmanager, Versionen wesentlicher Systemkomponenten,
Betriebsmetadaten, Fehlermeldungen und technische Protokolle.

Der Agent verwendet die UUID zur Identifizierung des Systems und das Agent token
zur Autorisierung der Kommunikation mit Firulai. Das Token wird lokal in einer
Konfigurationsdatei gespeichert, deren Zugriff auf SYSTEM und Administrators
beschraenkt ist.

Der Agent ist nicht dazu bestimmt, absichtlich Passwoerter, private Schluessel
oder Inhalte von Benutzerdokumenten zu erfassen. Technische Metadaten koennen je
nach Umgebung personenbezogene oder vertrauliche Informationen sein. Sie muessen
dies bewerten und die erforderlichen Schutzmassnahmen und Rechtsgrundlagen
anwenden.

5. HINTERGRUNDBETRIEB

Nach der Installation laeuft der Agent als automatischer Windows-Dienst, fuehrt
ein erstes Inventar aus, versucht taegliche Aktualisierungen, kann fehlgeschlagene
Uebermittlungen wiederholen und speichert lokale Konfiguration, Zustand,
Inventar und technische Protokolle. Er benoetigt HTTPS-Verbindung zu Firulai.

Die Deinstallation entfernt den lokalen Dienst und die Dateien, loescht aber
nicht automatisch bereits in Firulai gespeicherte Inventardaten. Das System kann
als getrennt oder inaktiv markiert werden; entfernte Daten sind in Firulai zu
verwalten.

6. SICHERHEIT UND AUTORISIERTE NUTZUNG

Sie duerfen den Agent nicht verwenden, um Computer ohne Erlaubnis zu

jeden Verdacht auf Offenlegung des Agent token oder unbefugte Nutzung.

Inventar- und Schwachstellenergebnisse koennen Fehler, Auslassungen, falsche
Positive, Verzoegerungen oder Abweichungen vom tatsaechlichen Zustand enthalten.
Pruefen Sie Ergebnisse, bevor Sie Entscheidungen zur Verfuegbarkeit, Integritaet
oder Sicherheit treffen.
